The Dimensions I chose to use for this website are almost all in percentages, the width is all in percentages
so that mobile users still have accessibility since their screen is smaller, the heights are mostly a static
height because it still needs to be able to fit all of the required content and in some instances it needs
to be longer than the other webpages I used. So those are the reasons I chose the dimensions that I did.


I used gradients in two different areas visible areas, on the buttons I used a circle gradient, and on the
header and footer I used a linear gradient. I also used diagonal gradient on the background but the background 
is covered so its really only 2.


The color scheme that I decided to use was chosen by me and not generated by adobe. I chose low saturation
colors to keep it easy on the eyes while also having a semi-formal, but welcoming feel to it. The sections 
I chose to make it a similar color to paper with a black border to make it pop. I used a calm green fading
to a calm blue color for the header and the footer to make it stand out. The buttons I made a nice dark blue
color to add some personality to the website.


A large portion of the general base html and css code was taken from previous stuff we covered in lectures
and I chose to build off of those baselines that we had. I did recieve assistance with my code from outside
the lectures. I got the code from w3's CSS and HTML webpages. I took this code because I could not figure out
how to do some select things that I wanted such as CSS height measurements, CSS display and formatting syntax,
and HTML special character syntax like "&lt;" for "<". I know I needed help from w3 for a few other pieces of
syntax but I can't think of any more specific examples.
