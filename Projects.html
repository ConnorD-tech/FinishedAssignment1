Welcome to My Projects!!

This page serves as a description of a bunch of my previous assignments, both academic and recreational. Feel free to ask me about any of these via my Contact page.


Learn How To Drive Manual

This was an app that I made a few years back in hopes of getting people to learn how to drive a manual car. I made it because as the years go on less and less people know how to drive manual so I wanted to change that. It was written in Javascript and it was fully functional giving very clear instructions every step of the way and even finished off with a test where the user is able to try it themselves with no instructions given.


Mapping Algorithm

This was an algorithm that I developed much more recently in Java where the program was given a maze via a data file, and then the algorithm found the way to the end of that maze. Now I will admit, it was inefficient and exponentially took longer and longer to map depending on how large the maze was, but it was interesting to build a program that typically requires much better skill sets and something that wasn't a standard user application.


Roblox Game

I tried my hand at making a Roblox game one time, the only issue was, I didn't know How to code in Roblox's primary coding language, Lua. So I spent days watching a youtube playlist that went through everything from placing items using code to polymorphism. I ended up settling on a progressive game about weight lifting. It was super bare bones and I managed to get basic animations and base functionality to the game. Unfortunately I have not gone back to that game and it still remains as an outline of a functional game.


General Scratch Projects

I have made COUNTLESS scratch projects over the years. They were always some sort of game but the games I made in grade 12 were significantly higher quality than the ones I made in grade 7. Some of these scratch projects include but not limited to: Flappy bird, The Worlds Hardest Game, A difficult platformer game, snake, and many MANY others. If it weren't for scratch I likely wouldnt have the interest in coding or computers that I do today. So in a way, scratch assisted in sparking my love for tech.
